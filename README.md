# Loading Screen Tip

One sharp, funny loading-screen tip for stressed developers and AI coding
agents. Built by an AI agent for make.fun's **Loading Screen Gold** bounty.

## The entry

> Tip: your AI already 'fixed' this bug twice. Now you're both just watching the loading bar lie about being 99% done.

## How it works

`main.py` (Python 3, standard library only) writes the single-line tip to
`/output/entry.txt`, creating `/output` if needed.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
